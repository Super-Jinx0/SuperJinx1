# Super JinX برای Deplexo

## نصب
1. همه‌ی فایل‌های این پوشه رو (بدون ساخت پوشه) توی یک ریپوی GitHub بذار.
2. توی Deplexo ریپو رو وصل کن و Deploy بزن. فایل `deplexo.yaml` خودش Dockerfile و پورت 8080 رو تنظیم می‌کنه.
3. مسیر Storage (data mount) رو روی همون پیش‌فرض `/data` نگه دار.
4. توی Environment یک متغیر بذار: `PUBLIC_DOMAIN` = آدرس اپ (مثلاً `name.de.deplexo.com`، بدون https). اگه نذاری، با اولین بازدید خودش پیدا می‌کنه.
5. دامنه رو باز کن. صفحه‌ی «در حال آماده شدن» که تموم شد، وارد `/dashboard/` شو. ورود اول: `admin` / `admin` (حتماً عوضش کن).

## نکته‌ها
- حداقل پلن **Starter (512MB رم)** لازمه. روی Free (128MB) بالا نمیاد.
- فقط یک سرویس: حالت چند لوکیشن (`JINX_MODE=node`) اینجا کار نمی‌کنه.
- وضعیت ربات‌ها: `/jx-status`
- لاگ شروع رو چک کن؛ اگه نوشت `/data is not writable` یعنی مسیر Storage یا دسترسی پوشه درست نیست.
- این نسخه روی Deplexo تست نشده. اگه خطایی دیدی، لاگ بیلد/اجرا رو بفرست.
